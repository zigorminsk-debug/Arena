## Высокий приоритет

### 1. Уведомление о завершении длинной задачи
Если Agent Mode работает долго, а пользователь свернул приложение — уведомление
«задача завершена». Реализуемо через JS-хуки состояния страницы, но хрупко:
зависит от вёрстки arena.ai. Делать только после проверки на реальном сайте,
после чего решение либо появится здесь, либо попадёт в «что сознательно не делаем».

### 2. Статус входа прямо в списке профилей
Сейчас состояние сессии видно только внутри профиля (экран «Диагностика»).
Можно показывать в карточке профиля: «вход сохранён в 14:20» / «нужно войти» —
по снимку `session_<id>.json`, который уже пишется при закрытии профиля.
Польза: видно, в каком аккаунте придётся вводить пароль, ещё до открытия.

## Средний приоритет

### 3. Работа без сети
Сейчас при ошибке загрузки показывается заглушка с кнопкой «Повторить».
Стоит добавить автоповтор при появлении сети (`ConnectivityManager.NetworkCallback`)
и понятное «нет интернета» вместо общей ошибки.

### 4. Черновик промпта по кнопке
При переключении профиля текст в поле ввода теряется. Автосохранение черновика
раздражает (текст «сам возвращается» в новом чате), поэтому только по явной
кнопке «Сохранить черновик» / «Вставить черновик».

### 5. Новые разделы Arena
`ProfileSections` — обычный список, поэтому добавление image/video arena или
страницы тарифов — это одна строка в `ALL` и адрес в `url()`; в настройках профиля
раздел появится сам.

### 6. Счётчики и размер релиза в CI
Показывать в summary размер APK и разницу с предыдущим релизом, чтобы замечать
рост размера (R8-сборка сейчас ~2.3 МБ).

## Технический долг

* **AGP / SDK**: обновить compileSdk/targetSdk (34 → 35/36) и AGP, проверить
  edge-to-edge на Android 15+ (сейчас окна не под системными панелями).
* **Тесты**: добавить Robolectric-тесты на мост (`WebBridge`), на `SessionKeeper`
  (нужен `CookieManager`) и на сценарии профилей. Чистая логика уже покрыта:
  профиль, обновления, разделы, резервные копии, разбор cookies.
* **Скрипты страницы**: сделано — `tools/selfcheck.py` проверяет `assets/js/*.js`
  через `node --check` и сверяет имена файлов со `Scripts.kt`.
* **Совместимость**: держать проверку «профильные процессы в манифесте» и «имена
  для R8» — они уже ловят поломки, которые иначе доходят до пользователя.

## Что сознательно не делаем

* **Автосохранение черновика промпта** — см. пункт 4: только по кнопке.
* **Синхронизация cookies между устройствами** — это передача чужих сессий,
  риск утечки выше пользы. Резервная копия сознательно содержит только метаданные.
* **Парсинг страниц arena.ai ради «нативных» экранов** — сайт меняется без
  предупреждения; WebView-оболочка надёжнее.
